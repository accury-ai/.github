# ACCURY GitHub Profile Guide

This repository stores ACCURY organization profile content.

## Scope

- Main editable content is `profile/README.md`.
- Keep the profile concise, public-facing, and aligned with the positioning on accury.ai. Write the company name as `ACCURY`, not "ACCURY AI".
- Product names, taglines and status (Live, Available, Planned) come from the website's product list; mark planned products as Planned.
- `profile/accury-s01.svg` (light mode) and `profile/accury-white.svg` (dark mode) are copies of the wordmark from the ACCURY Design Book (`media-kit` repo, `kit/logos/wordmark/svg/`). Replace them from there; do not redraw them.
- Do not add application or brand-asset implementation details here; link or summarize only when needed.

## Style

- Prefer plain, direct language over marketing-heavy copy.
- Keep headings short and easy to scan.
- Preserve Markdown compatibility with GitHub profile rendering.

## Git

Use small commits for profile changes, for example `docs(profile): refine ACCURY AI overview`.
